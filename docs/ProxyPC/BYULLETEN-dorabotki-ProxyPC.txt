1. ЗАЧЕМ БЫЛА ДОРАБОТКА
-----------------------
1) Proxy PC периодически «перезапускался» сам (ложные reconnect).
2) Cursor ломался, если в settings.json оставался прокси на мёртвый
   socks5://127.0.0.1:1080 после выключения Proxy PC.
3) Нужно, чтобы Cursor работал с ЛЮБЫМ одним VPN-клиентом
   (Bebra / Happ / Amnezia / Proxy PC) при раздельном включении.
4) Пользователь переключает клиенты САМ — без автогашения и без
   «ожидания отключения» чужого VPN внутри Proxy PC.

2. ЧТО ИЗМЕНИЛОСЬ В ПОВЕДЕНИИ
-----------------------------
A. Сторожок (watchdog)
   - Интервал проверки: ~8 с (раньше ~0.7 с).
   - Живость стека: по процессам ssh + proxy-helper, не по флакам TCP.
   - Пауза между reconnect ≥ 30 с, не больше 2 попыток подряд.
   - Не переписывает ярлык рабочего стола на каждом тике.

B. Режим туннеля
   - Рабочий режим: SSH → SOCKS 127.0.0.1:1080 → HTTP 127.0.0.1:8080
     (proxy-helper / gost) → системный WinINET-прокси Windows.
   - Чужие VPN (Bebra/Happ/Amnezia) Proxy PC НЕ убивает и НЕ ждёт.
   - Переключение: пользователь сам выключает один клиент и включает другой.

C. Cursor и Proxy PC (важно)
   - Cursor/Electron НЕ использует WinINET сам по себе.
   - Пока Proxy PC ON и порт 8080 слушает, скрипт пишет в
     %APPDATA%\Cursor\User\settings.json ТОЛЬКО:
       http.proxy           = http://127.0.0.1:8080
       http.proxySupport    = override
       http.proxyStrictSSL  = false
     плюс оставляет/ставит cursor.general.disableHttp2 = true
   - При Proxy PC OFF эти три ключа (proxy*) ПОЛНОСТЬЮ удаляются.
   - ЗАПРЕЩЕНО снова писать socks5://127.0.0.1:1080 в Cursor.
   - Для Bebra / Happ / Amnezia (TUN/TAP) в Cursor http.proxy быть
     НЕ должно — трафик идёт через ОС.

D. Системный прокси Windows
   - ON:  ProxyEnable=1, ProxyServer=127.0.0.1:8080
   - OFF: ProxyEnable=0
   - Не путать с прокси Happ (часто 127.0.0.1:10809).

3. КАК РАБОТАТЬ (ШТАТНО)
-----------------------
Один канал за раз.

  Нужен Bebra / Happ / Amnezia:
    1) Proxy PC OFF (ярлык / трей)
    2) В Cursor нет http.proxy (скрипт снимает при OFF)
    3) Включить нужный VPN в его приложении
    4) При смене настроек Cursor — полный перезапуск Cursor

  Нужен Proxy PC:
    1) Выключить Bebra / Happ / Amnezia в их приложениях
    2) Proxy PC ON
    3) Полный перезапуск Cursor (чтобы подхватил http://127.0.0.1:8080)
    4) Проверка: чат «привет»; IP через прокси ≈ 185.125.103.179

Без любого VPN провайдер режет Cursor — агент не работает.
Не оставлять ноль VPN при переключении: сначала включить следующий,
убедиться, потом выключить предыдущий — или быстро сменить, но не
оставлять «дыру» надолго.
