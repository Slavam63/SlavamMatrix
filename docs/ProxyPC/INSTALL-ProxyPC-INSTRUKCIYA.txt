ЧТО ТАКОЕ Proxy PC (коротко)
----------------------------
Локальное приложение-трей:
  SSH-туннель на VPS → локальный SOCKS 127.0.0.1:1080
  → HTTP-прокси 127.0.0.1:8080 (gost.exe)
  → системный прокси Windows = 127.0.0.1:8080

Включение/выключение: ярлык «Proxy PC» на рабочем столе (двойной клик).
Зелёный щит / «on» ≈ включено, синий / «off» ≈ выключено.

Amnezia и Outline/Shadowsocks — ОТДЕЛЬНЫЕ сервисы обхода.
Их НЕ смешивать с установкой Proxy PC в одном запуске.
Ключи для них лежат в подпапке ProxyPC-Keys (если понадобятся позже).
